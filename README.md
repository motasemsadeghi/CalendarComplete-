# تقویم — نسخهٔ وب (PWA)

تاریخ امروز به‌صورت جلالی، زرتشتی، طبری، میلادی و ترکی، تولد بعدی و مناسبت روز. بدون اینترنت هم کار می‌کند و به هیچ سرویسی وصل نیست.

## اجرا
    python3 -m http.server 8000

## انتشار
GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
نصب روی گوشی: Add to Home Screen. نسخهٔ ویجت iOS در `scriptable/` است.
